# 🐦 Bird Species Observation Analysis

## 📌 Project Overview

This project analyzes bird species observations across **Forest and Grassland habitats**. The goal is to understand bird diversity, habitat patterns, environmental conditions, and conservation-related observations through an interactive Streamlit dashboard.

## 🎯 Objectives

- Analyze bird species distribution
- Compare Forest and Grassland habitats
- Identify the most frequently observed bird species
- Analyze environmental conditions such as temperature, humidity, sky, and wind
- Study bird observations by month and other categories
- Provide useful business/analytical insights through an interactive dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Matplotlib
- Seaborn
- Streamlit
- Jupyter Notebook

## 📊 Dashboard Features

- 🏠 Dashboard
- 🐦 Species Analysis
- 🌳 Habitat & Environment Analysis
- 🛡️ Conservation Analysis
- 📋 Data Explorer
- 🔎 Interactive Filters
- 📈 Interactive Charts and KPIs
